# App logos

Logos are not included, because they belong to each brand. Create a folder `logos/clean/` next to `index.html` and add your own transparent PNGs there with these names:

| App | File |
| --- | --- |
| YouTube | youtube.png |
| Netflix | netflix.png |
| Prime Video | prime-video.png |
| Spotify (Music tile) | spotify.png |
| YouTube Music | youtube-music.png |
| Weather | weather.png |
| Showmax | showmax.png |
| Live | live.png |
| Assistant icon on the clock screen | assistant.png |

Square images around 256 x 256 px work best. Until a file exists, the tile shows a simple symbol instead.
